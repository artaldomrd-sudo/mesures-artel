Usuarios y roles

👥 Cada persona entra a la plataforma con su cuenta de Google. Aquí decides quién puede entrar y con qué permisos (roles). Una persona puede tener varios roles a la vez (ej. contable + comunicaciones). Los cambios aplican la próxima vez que la persona inicie sesión.

🔐 Verificación en 2 pasos (app autenticadora)

Obligatoria para admin al iniciar sesión, y el código se pide cada vez que se entra a esta pantalla. Los demás roles entran con su PIN o Face/Touch ID. La consola de Firebase solo ofrece SMS; el método con app autenticadora (Google Authenticator / Authy) se activa desde aquí.
