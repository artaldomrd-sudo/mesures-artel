Registrar compra a proveedor

Para artículos que no pasan por fábrica (comprados ya hechos a un proveedor: tubos, puertas, vidrios, etc.). Se sube la orden de compra y, cuando esté lista para cargar, aparece para chofer e instalador.

Mientras esté Pendiente de confirmación de proveedor no le aparece al chofer. Cámbialo a Listo para cargar cuando el proveedor confirme.
